# Data

`instruments.csv` — one row per negotiating pair (n = 149), 64 columns.

Source: Soldà, Ke, von Hippel & Page (2021), *Psychological Science* 32(10). The authors' data and analysis code are public on OSF: <https://osf.io/km8c9/>. This file is the version distributed in class.

Columns used in the lab:

| Column | Meaning |
|---|---|
| `final_pot_perc` | % of the initial prize still awarded at the end of the negotiation (pair level) |
| `sum_belief` | Participant's + partner's posterior belief (0–100 each) of having out-performed the other |
| `ball` / `other_ball` | 1 if the participant / partner saw a green ball (signal "you probably did better") |
| `score_p2` / `other_score2` | Correct answers of the participant / partner in the partner phase |

Other columns (demographics, chat coding, timing) are described in the supplementary material at <https://osf.io/2j6ne/>.
